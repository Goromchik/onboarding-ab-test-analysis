# Анализ A/B-теста для нового процесса адаптации пользователей
В рамках этого проекта анализируется влияние нового дизайна процесса адаптации на коэффициент конверсии пользователей. В ходе эксперимента сравниваются контрольная и экспериментальная группы, чтобы определить, повышает ли новый процесс адаптации конверсию и вовлеченность пользователей.

## Цель проекта
Оценить, повысил ли новый процесс адаптации конверсию по сравнению с исходным вариантом.

## Бизнес-вопрос
Повысил ли новый дизайн процесса адаптации коэффициент конверсии для новых пользователей и является ли этот эффект статистически значимым?

## Набор данных
В проекте используются синтетические экспериментальные данные, сгенерированные для реалистичного сценария онбординга. Набор данных содержит следующие поля:

- user_id — уникальный идентификатор пользователя.
- variant — группа пользователя в эксперименте:
  - control — контрольная группа
  - treatment — экспериментальная группа
- signup_date — дата регистрации пользователя.
- acquisition_channel — канал привлечения:
  - organic
  - paid_search
  - referral
  - social
- device_type — тип устройства:
  - desktop
  - mobile
  - tablet
- region — регион пользователя:
  - NA
  - EU
  - APAC
  - LATAM
- onboarding_step_completed — бинарный признак завершения ключевого шага процесса адаптации.
- session_count — количество сессий пользователя.
- completed_onboarding — бинарный признак завершения полного процесса адаптации.
- converted — целевой результат эксперимента:
  - 1 — пользователь выполнил целевое действие
  - 0 — пользователь не выполнил целевое действие
- time_to_conversion — время до конверсии. Для пользователей без конверсии значение может быть пустым.
- revenue — выручка, полученная от пользователя. Для пользователей без конверсии значение обычно равно 0 или NaN.

- Python
- pandas

- statsmodels
- Plotly

## Структура проекта
- `scripts/generate_experiment_data.py` — создает синтетические экспериментальные данные
- `data/raw/experiment_data.csv` — исходный набор данных эксперимента
- `sql/experiment_metrics.sql` — SQL-запросы для расчета основных метрик эксперимента
- `src/stats.py` — функции для расчета воздействия и статистической значимости
- `app/dashboard.py` — интерактивный дашборд на Streamlit

## Методология
1. Генерация синтетических данных для моделирования эксперимента.
2. Проверка корректности разделения пользователей на контрольную и тестовую группы.
3. Расчет коэффициента конверсии по вариантам.
4. Проверка SRM (sample ratio mismatch) на корректность случайного распределения.
5. Оценка достаточности объема выборки через power analysis.
6. Расчет абсолютного и относительного прироста.
7. Проверка статистической значимости с помощью z-test для долей.
8. Визуализация результатов в интерактивной панели управления.

## Результаты
| Метрика | Control | Treatment | Изменение |
|---|---:|---:|---:|
| Conversion rate | 23.71% | 29.07% | +5.36 п.п. |
| Relative uplift | — | — | +22.59% |
| p-value | — | — | p < 0.001 |

## Бизнес-интерпретация
Редизайн онбординга дает положительный эффект на конверсию: +5.36 процентных пунктов относительно контрольной группы (+22.59% к исходному уровню). Эффект статистически значим (p < 0.001), что делает новый сценарий кандидатом на масштабирование при подтверждении на реальных данных.

## Ограничения
- Данные синтетические: эффект заложен намеренно, а не извлечен из реального бизнеса. Цель проекта - показать корректную методологию A/B-анализа, а не предлагать окончательное продуктовое решение.
- В текущей версии основное внимание уделено методике и визуализации, а не полному разбору сегментных эффектов и guardrail-метрик.
- Для реального продуктового решения дополнительно понадобятся: более длинное окно наблюдения, проверка эффекта новизны, анализ по каналам привлечения, устройствам и регионам, а также оценка дополнительных метрик качества и экономической эффективности.
